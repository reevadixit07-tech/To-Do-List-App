# 📝 To-Do List

A simple and responsive task manager built with **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript fundamentals while building something practical. It lets you add tasks, assign dates, mark them as completed, and remove tasks when they're no longer needed.

## ✨ What It Does

* Add new tasks to your list
* Set a date for each task
* Mark tasks as completed
* Delete tasks you no longer need
* Keep tasks saved using **Local Storage**
* View your tasks even after refreshing or reopening the browser
* Responsive layout for different screen sizes
* Clean and minimal interface

## 🛠️ Built With

* **HTML5** — page structure
* **CSS3** — styling, layout, and responsive design
* **JavaScript** — task management and application logic
* **Local Storage** — saving tasks directly in the browser

## 💡 How It Works

The application runs entirely in the browser, so there is no backend or database involved.

When a task is created, its information is stored in the browser's Local Storage. This means the task list remains available when the page is refreshed or opened again later.

JavaScript handles the main interactions, including creating tasks, changing their completion status, and removing them.

## 🚀 Running the Project

No installation or additional packages are required.

1. Clone the repository:

```bash
git clone https://github.com/reevadixit07-tech/To-Do-List-App.git
```

2. Open the project folder.

3. Open the main HTML file in your browser.

That's it — the application runs directly on the client side.
